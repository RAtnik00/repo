Version and compatibility

Original version 2.1.0; translated package 2.1.0+translation2. Upstream lists iOS 14–17. This package is rootless iphoneos-arm64 (/var/jb); practical compatibility depends on a compatible jailbreak, tweak injection and PreferenceLoader.

Zone 2.1.0 changes

  • Fixes the Lock Screen poster panel when double-tap-to-lock is disabled.
  • Fixes a black screen when the tweak is enabled without a selected wallpaper.
  • Adds separate video-loop controls for the Lock Screen and Home Screen.
  • Updates the settings UI and includes other fixes.

Localization update 2.1.0+translation2

The author, channel, icon-credit and repository lines under the icon now switch between English, Russian and Ukrainian. Clickable links are preserved. The package title is simply Zone; it uses the original author's icon. The original Zone executable files are unchanged.

О версии и совместимости

Оригинальная версия — 2.1.0, переводной пакет — 2.1.0+translation2. Автор указывает поддержку iOS 14–17. Этот пакет предназначен для rootless iphoneos-arm64 (/var/jb); совместимость зависит от джейлбрейка, подмены библиотек и PreferenceLoader.

Изменения Zone 2.1.0

  • Исправлено появление панели постеров на экране блокировки при выключенном двойном касании для блокировки.
  • Исправлен чёрный экран, возникавший при включённом твике без выбранных обоев.
  • Добавлены отдельные переключатели повтора видео для экрана блокировки и домашнего экрана.
  • Обновлён интерфейс настроек и исправлены другие ошибки.

Локализация 2.1.0+translation2

Подписи автора, канала, дизайна иконки и репозитория под изображением переключаются между английским, русским и украинским. Ссылки остаются кликабельными. В менеджере пакетов название — просто Zone; используется иконка автора.
