NextClock stable releases

Testing a beta? Return to 1.1.0, the latest stable release. Older packages remain in the repository for version selection in your package manager.

Download the .deb below and open it in your package manager to install the selected version. Follow its prompts to restart SpringBoard. You do not need to delete your preferences or imported packs. Beta-only settings will not be available in older versions.

These downloads are for rootless jailbreaks. iOS 15 is supported; iOS 16–17 remains experimental in 1.1.0. Older releases have more limited compatibility. This page contains stable releases only.
