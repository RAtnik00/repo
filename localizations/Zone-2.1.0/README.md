# Zone 2.1.0 — English, Russian, Ukrainian

Unofficial text localization for the original Zone tweak by iosdump (iosdumpzzz). Translation helper by RAtnik00. Original Zone 2.1.0 executables are unchanged.

The package is named **Zone** and targets rootless `iphoneos-arm64` (`/var/jb`). It includes the author's original icon, five localized preference labels, and all 130 Chinese strings in ZonePrefs 2.1.0. The credit block under the icon is translated into English, Russian and Ukrainian while preserving clickable author links.

Upstream lists support for iOS 14–17. This package specifically targets rootless arm64; actual compatibility depends on the jailbreak environment and a compatible PreferenceLoader/tweak injection setup. Physical-device UI behavior still needs confirmation.

**Upstream 2.1.0 changes:** fixes to the Lock Screen poster panel when double-tap-to-lock is disabled, a black screen when the tweak is enabled without a selected wallpaper, Lock/Home Screen video-loop controls, a settings UI update, and other fixes.

Original author and repository: [iosdumpzzz/iosdump.repo](https://github.com/iosdumpzzz/iosdump.repo).
