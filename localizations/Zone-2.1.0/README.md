# Zone 2.1.0 — English, Russian, Ukrainian

Unofficial text translation for the original Zone tweak by iosdump (iosdumpzzz). Translation and localization helper by RAtnik00. The original Zone 2.1.0 executable binaries are unchanged.

The `iphoneos-arm64` package targets the rootless layout shown in the supplied device screenshots (`/var/jb`). It contains 5 localized Root.plist labels and all 130 Chinese UTF-16 strings extracted from the ZonePrefs 2.1.0 binary, including updated wallpaper descriptions and the new loop-playback settings. Languages are selected from the iPhone's system language.

The package was built for arm64 and includes an arm64/arm64e runtime helper. Its archive contents and preservation of the original ZonePrefs and Zone binaries were verified. Physical-device installation and UI behavior still need confirmation.

Upstream author repository: https://github.com/iosdumpzzz/iosdump.repo
